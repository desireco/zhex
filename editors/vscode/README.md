# Zhex for VS Code

Syntax highlighting and `.zhex` file recognition for the experimental Zhex language. Includes line comments, bracket matching, and four-space indentation defaults.

Install the locally built `zhex-0.0.1.vsix` through **Extensions: Install from VSIX**. Full build and installation instructions are in the repository's `docs/editors.md`.

This package provides syntax highlighting. Language-server completion, diagnostics, and formatting are future work.
